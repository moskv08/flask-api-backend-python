# Opencode Commands

This directory contains custom opencode commands that can be used to automate various development tasks.

## Available Commands

- **brainstorm.md** - Generate ideas and solutions for development tasks
- **commit.md** - Assist with commit message generation and validation
- **db-migration.md** - Help with database migration tasks
- **debug.md** - Provide debugging assistance and troubleshooting tips
- **doc.md** - Generate documentation for code and features
- **explain.md** - Explain code and development concepts
- **implement.md** - Assist with implementing new features or functionality
- **plan.md** - Create development plans and task breakdowns
- **review.md** - Help with code review processes
- **test.md** - Assist with testing and test creation

## Usage

Each command file contains specific instructions on how to use it. These commands can be executed through the opencode interface or by following the specific guidelines outlined in each file.

## Contributing

To add new commands, create a new markdown file in this directory following the existing pattern.
