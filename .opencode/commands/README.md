# Opencode Commands

This directory contains custom opencode commands that can be used to interact with the project.

## Available Commands

- `brainstorm` - Generate ideas and solutions for development tasks
- `commit` - Assist with creating commit messages and managing git operations
- `debug` - Help debug issues in the codebase
- `doc` - Generate documentation for code and features
- `explain` - Explain code and functionality in detail
- `flask-review` - Review Flask-specific code and architecture
- `plan` - Create development plans and task breakdowns
- `review` - Conduct code reviews and quality assessments
- `test` - Generate tests and assist with testing workflows

These commands can be invoked using the opencode CLI tool.
