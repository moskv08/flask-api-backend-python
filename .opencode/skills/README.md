# Opencode Skills

This directory contains custom opencode skills that provide specialized instructions and workflows for particular tasks.

## Available Skills

- `flask-conventions` - Coding conventions and patterns for this Flask API project
- `issue-driven-dev` - A structured software development lifecycle for taking an identified issue through to a safe, controlled implementation
- `python-style` - Python code style rules for this project
- `security-rules` - Security requirements to enforce in all code
- `tdd-enforcement` - Enforces strict test-driven development for any new functionality in the Flask project
- `testing-patterns` - How tests are written in this project

These skills can be invoked using the opencode CLI tool.
